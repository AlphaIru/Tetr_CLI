## Basic Controls:
- Menu
    - Confirm: Enter
    - Go back: Escape
    - Move: Arrow Keys
- In Game (Default):
    - Left: Left Arrow
    - Right: Right Arrow
    - Rotate Right (CW): Up Arrow or X
    - Rotate Left (CCW): Z or Ctrl
    - SoftDrop: Down Arrow
    - HardDrop: Space
    - Hold: C
    - Restart: R
